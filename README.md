# Demi Studio 攝影官網與後台

Demi Studio 提供婚紗婚禮、商業攝影、作品瀏覽、常見問題和聯絡頁。工作室可透過後台編輯圖文、作品、FAQ 和方案，先儲存草稿與預覽，再發布到前台。

## 本機啟動

需要 Node.js 24。在專案根目錄執行：

```bash
npm ci
npm run dev -- --host 127.0.0.1 --port 5313
```

- 前台使用 `http://127.0.0.1:5313/`。
- 後台使用 `http://127.0.0.1:5313/admin`。
- 全新資料目錄會初始化帳號 `admin`，初始密碼存在 `.demi-local/admin-password.txt`。既有本機帳號沿用原密碼。
- 管理員先輸入帳密，再用驗證器 App 加入時間型帳號。手動輸入畫面金鑰與六位數驗證碼，完成後保存一次性復原碼。金鑰與復原碼請放在安全的密碼管理工具內。初始密碼檔會在綁定後清除。
- 登入時可使用驗證器的當期驗證碼，或一組未使用的復原碼。每組復原碼只能使用一次。

## 正式模式驗證

```bash
npm run build
npm start
```

預設使用 5313 埠，需要與開發站並行時請另設 `PORT`。測試時可用 `DEMI_DATA_DIR` 指向獨立資料目錄。正式上線須提供 Node.js 常駐主機、HTTPS、自訂網域與持久化磁碟。請參閱 [部署與網域設定](docs/DEPLOYMENT.md)。

## 權限與編輯流程

| 角色 | 帳號管理範圍 |
| --- | --- |
| 管理員 | 固定一位，擁有全部權限及備份、還原與稽核功能 |
| 老闆 | 最多一位，可管理組長及員工 |
| 組長 | 可管理員工 |
| 員工 | 可使用指派的內容操作權限 |

後台分別控制草稿預覽、編輯、上傳、發布與回復操作。共同草稿使用版本編號。若他人先儲存，後台會拒絕舊版寫入並保留當前頁面的編輯。先複製未存變更，再載入最新版並手動合併。

## 備份與稽核

「備份與操作紀錄」僅供管理員使用。內容備份保存草稿、公開與上一個發布版本及上傳圖片。還原前會自動建立一份保護備份。還原保留當前帳號、權限、雙重驗證和稽核紀錄。畫面顯示最近 100 筆權限變更、發布、版本回復和備份操作，並保留操作人與時間。操作紀錄保存在本機檔案，屬於可由主機管理者存取的紀錄。

主機故障時，以停機時建立的加密站外備份還原整個資料目錄。請將備份限制在授權管理者可存取的儲存空間。備份與還原的細節見 [資安與備份手冊](docs/CMS_SECURITY.md)。

## 程式與資料位置

| 路徑 | 用途 |
| --- | --- |
| `src/content/` | 前台預設圖文、作品、FAQ 和方案 |
| `src/views/AdminView.vue` | 管理員驗證、內容編輯、備份和稽核介面 |
| `server/` | Node.js 正式服務、登入、授權、JSON 儲存 |
| `DEMI_DATA_DIR` | 帳號、密碼雜湊、驗證器金鑰、內容、圖片及備份。預設為 `.demi-local/` |

專案使用 Vue 3、TypeScript、Vite、Tailwind CSS 與 Sharp。後台採單一 Node.js 實例與 JSON 檔案保存資料。Git 僅保存程式、網站公開素材及文件，部署時請使用獨立的正式帳號與資料目錄。
