# Demi Studio 後台與獨立網站規劃

## 本機測試

在專案資料夾執行 `npm run dev -- --host 127.0.0.1 --port 5313`，然後開啟 `http://127.0.0.1:5313/admin`。固定管理者帳號為 `admin`，初始密碼在 `.demi-local/admin-password.txt`。變更密碼後以新密碼登入，初始密碼檔不代表目前密碼。

草稿、公開版本及上一版保存在 `.demi-local/content.json`，上傳圖片保存在 `.demi-local/media/`。編輯後先儲存，再開啟草稿預覽，確認後發布到本機。重新整理公開頁面即可看到更新。備份時請保存內容檔與圖片資料夾。

本機帳號與雜湊密碼保存在 `.demi-local/accounts.json`。登入後在「帳號與權限管理」建立老闆、組長或員工，並設定草稿預覽、內容編輯、圖片上傳、發布和版本回復。

| 角色 | 可管理帳號 |
| --- | --- |
| 管理者 | 固定一位，擁有所有操作權限，可管理老闆、組長及員工 |
| 老闆 | 限一位，可管理組長和員工 |
| 組長 | 可管理員工 |
| 員工 | 可使用帳號授權的功能 |

帳號可停用。管理下級帳號時，只能調整自己持有的操作權限。若下級持有自己沒有的權限，密碼須由更高權限者重設。各人仍可自行變更自己的密碼。正式主機的登入、資料庫、物件儲存與網域另行建置。

## 第一版後台

保留現有 Vue 前台。工作室人員登入 `/admin` 後，可維護首頁與服務頁的圖文、作品、FAQ 和方案。由網站管理者開設帳號，客戶透過授權的工作室帳號編輯本站內容。

| 功能 | 第一版驗收 |
| --- | --- |
| 頁面圖文 | 可調整標題、正文、主圖、替代文字與圖片焦點，並預覽手機及桌機畫面 |
| 作品管理 | 可上傳圖片、分類、排序、調整焦點及上下架 |
| FAQ | 可新增、編輯、排序、分類和隱藏問答，公開內容集中在 `/faq` |
| 方案 | 可編輯方案名稱、參考價格、說明、交付項目與顯示順序，使用穩定的方案 ID 串接詢問頁 |
| 發布 | 儲存草稿、預覽、發布和回復上一版本。發布前確認引用的圖片仍有效 |

## 資料與圖片

- 資料庫保存頁面區塊、作品、FAQ、方案、圖片中繼資料及發布版本。以現有 `src/content` 作為首次匯入資料，核對文字、分類、排序與圖片連結。
- 物件儲存保存圖片檔案，資料庫記錄儲存鍵、尺寸、替代文字與焦點。縮圖供作品列表使用，較大尺寸供燈箱與橫幅使用。公開網站只讀取已發布的圖片版本。
- 後端驗證編輯權限、圖片類型與檔案大小。草稿預覽需要授權。管理者可邀請編輯者，第一版由管理者發布。被公開版本引用的圖片須先解除引用才可移除。
- 新舊內容交接時先讓現有前台讀取一個已發布的測試版本，核對各頁後再切換。資料庫與圖片需要各自備份，驗收時實際測試回復。

## 上線順序

1. 先在本機完成後台、內容匯入與發布驗收。詢問表單沿用現在的展示流程。
2. 建立測試環境，驗證登入權限、上傳、草稿、發布、回復、圖片顯示與正式詢問收件。
3. 工作室確認網域名稱、所有人及費用後，再註冊並連接正式主機。檢查 DNS、HTTPS、主網域轉址、網站地圖、社群分享圖與正式表單收件。
4. 上線前由工作室保有網域、主機、資料庫及圖片空間的帳戶管理權，並確認續費、備份與交接方式。

第一版以單一工作室為範圍。若未來要為多間工作室提供各自的後台、網域與媒體空間，再規劃站點隔離與獨立權限。
